Guía de Configuración

Sigue estos sencillos pasos para conectar tu Google Sheets con esta aplicación:

1

Crea la Hoja de Cálculo

Crea una nueva hoja de cálculo en tu Google Drive. Las pestañas (Obras, Iniciativas, Formaciones, Actividad) y columnas se crearán automáticamente al realizar los primeros envíos.

2

Abre Apps Script

Dentro de tu hoja de cálculo, haz clic en el menú superior Extensiones ➔ Apps Script.

3

Pega el Código del Script

Reemplaza todo el contenido en el editor con el código puente. Puedes encontrar el archivo google_apps_script.gs en el directorio raíz de este proyecto.

4

Implementa como Aplicación Web

Haz clic en el botón azul Implementar ➔ Nueva implementación. Selecciona el tipo de engranaje Aplicación web y configura:

  • Ejecutar como: Mismo usuario (tú)
  • Quién tiene acceso: Cualquiera

Haz clic en Implementar, autoriza los permisos y copia la URL generada que termina en /exec.

5

Pega la URL en la Aplicación

Pega la URL copiada en la pestaña de configuración de esta app y pulsa en "Conectar y Sincronizar".
